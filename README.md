## How this is built

`scripts/generate_catalog.py` scans every CloudDrove organisation through the GitHub API, reads each repository tree to enumerate `modules/` submodules, and enriches with Terraform Registry download counts. It runs nightly through [`.github/workflows/catalog.yml`](.github/workflows/catalog.yml), using only the standard library and the built-in `GITHUB_TOKEN`.

```bash
GITHUB_TOKEN=$(gh auth token) python3 scripts/generate_catalog.py
```
